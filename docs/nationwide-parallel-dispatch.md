# Nationwide research and parallel dispatch

The worker runs up to four automation requests concurrently, independently of pure screening. Claims start no faster than one per second and every attempt obtains a fresh database capability. One held provider request no longer blocks all other accounts. Failure backoff is per lane, pending requests remain bounded, and shutdown drains known attempts without claiming replacements.

Global call-launch spacing is three seconds instead of thirty. This changes how quickly vacant slots can fill, not the provider cap: the verified configuration allows eight outgoing calls and reserves two incoming slots. Account funding determines its existing one-to-three-call limit. Database capacity checks, recipient call spacing, requested-callback priority, account fairness, opt-outs, local calling hours, manual controls and actual-cost settlement remain in force. Unknown provider outcomes are never redialed automatically.

Free DealMachine ZIP metadata now covers all US states and DC that pass the existing research-state policy, rather than only the three states in the initial shortlist. On October 23, 2026, that policy admits 38 states and DC. Four independently leased pages (up to 400 metadata rows) are refreshed each minute through the shared provider limiter. Unvisited states take priority; failed pages retain their retry times. This endpoint does not consume property-research credits.

Each nationwide account can add another 200 fresh ZIPs every ten minutes when discovery runs. Already-current ZIPs no longer fill the same first 200 positions on every refresh. Existing ZIP cooldowns, assignments and saved location restrictions are preserved. Paid property retrieval still requires the account's existing funding allowance; duplicate-only or empty discovery remains platform-covered.

Local verification covers overlapping blocked requests, independent screening, concurrency limits, fresh capabilities, shutdown, backoff, real SQL issuer selection and three-second timing, all eligible state sources, metadata failure isolation, expansion beyond 200 ZIPs and explicit customer scope. No paid provider tests are used.
