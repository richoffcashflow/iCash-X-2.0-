# Beginner-first one-page experience
Implemented in the preview: one start action; one $20 funding entry; credits and bot status above property progress; current action and next step; two latest milestones; full evidence/history opened inline; closing checklist hidden until requested; plain-language explanations at contract and title milestones; recommended hold-limit action; distinct payment-received label; accessible pause/restart and credit disclosures.

No campaign, property-type, prompt, sequence or assistant-name configuration is added. Account signup is still not required for the demo. Funding stays disabled until real payment infrastructure is ready. The demo and stock photo remain labeled.

Preserved product requirements for live integration: guided first-closing mode, approved limits and signing authority, verified owner participation, buyer backup plans, title exceptions, context-aware human support, and real multi-deal records. These are not represented as working live features by this UI commit. User should receive an understandable recommendation instead of a blank negotiation question. Never promise a deal or represent an estimated spread as payment received.

Frontend changes were submitted through GitHub because the execution workspace was unavailable; Vercel build and deployed browser verification are the available verification paths.
