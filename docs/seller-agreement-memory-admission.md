# Seller agreement memory admission — reconstruction checkpoint

This is an unfinished source checkpoint. It is not a release candidate. The migration has not been installed. Native contention tests, final result pins, composed application tests and independent review remain required.

Automatic seller agreements in the existing shared-memory cohort must retain the exact canonical source fingerprint reviewed by the service. The six-argument claim/defer RPCs require that fingerprint. The seven-argument forms additionally retain an immutable live-call prefix proof for narrowly reviewed completion of that same original call. The old five-argument forms hold for enabled accounts and preserve disabled-account behavior. None has overlapping default arguments.

The private receipt binds the original confirmation, account, deal, screening, phone, call, canonical source manifest and live-call identities. It does not replace original offer, signer, contact, financial, Pause or cancellation admission. The public canonical memory projection and generic cancellation-only signing guard remain unchanged. The final document-create boundary is `icash_begin_signing`; a new source committed afterward can leave the one original provider document created, but the final contract-text claim must hold. This change must never expire or recreate that original solely because its conversational source changed.

Source writers serialize on the existing recipient advisory key 74 before their source row changes: authenticated SMS ingress and delivery receipts, outbound result persistence, legacy/full inbound history, memory retention, and terminal inbound call clocks (both the outer worker finisher and its transition). Enabled legacy-history retention is narrowed to the fenced account/screening/contact. The admission helper rejects a newly committed source that the public projection would omit behind the transaction's earlier `now()` boundary. The ordinary final text claim already holds the same recipient lock.

The exact original contract-link message is excluded from its own fingerprint only after matching the saved confirmation, envelope, signer, thread, phone and strict contract-link shape. Seller replies and every unrelated outbound message remain in source evidence. Missing or ambiguous admission evidence holds automatic creation and delivery.

Deferred recovery may refresh only the original source fingerprint after the application proves the immutable call prefix, original consent/price/recipient and neutral remainder. SQL also requires the same nonoriginal source manifest, original completed call identity, expected fingerprint, live-call identities and an unchanged claimed original recovery without any purchase envelope. Missing prefix proof cannot be invented retrospectively. Every accepted refresh has an immutable journal row; no workflow flag or prior provider operation is reset.

`scripts/build-seller-memory-admission.mjs` reconstructs byte-identical config and CLI-created migration from captured predecessor definitions and the reviewed body file. Those fixtures contain function definitions and metadata only. The final migration must carry exact predecessor and result source/ACL/ownership pins and run once in the migration runner's transaction with its ledger, shared lock and bounded timeouts.
